# NCDAI on mobile

NCDAI ships two installable mobile experiences. Both are progressive web apps: they install from the browser on Android and iOS, open full-screen from the home screen, and need no app store.

## 1. NCDAI Consult (offline quick consult) · `/mobile/`

A phone-first consult tool for clinicians. Enter the findings, tap **Generate consult**, and get the safety triage plus the full consultant synthesis: problem list, targets, stepwise guideline-linked plan, medication review, monitoring, follow-up, and a summary to copy into the notes.

- Runs entirely on the device. Nothing entered is stored or sent, so it works without a connection and without an account.
- Uses [`frontend/mobile/engine.js`](../frontend/mobile/engine.js), a port of the backend safety rules and consultant engine. `backend/tests/test_engine_parity.py` requires identical output to the Python engine on the 66-case catalogue, targeted scenarios and 1,500 seeded random patients. The dose-reference module is not included offline.
- Four fictional example patients open the app in a working state and are labelled as examples.
- Sources: [`page.html`](../frontend/mobile/page.html), [`app.js`](../frontend/mobile/app.js), [`evidence.js`](../frontend/mobile/evidence.js) (generated by `scripts/export_mobile_evidence.py`). `npm run build` packages them into `public/mobile/`.

## 2. NCDAI 2.0 workspace · `/`

The full clinical workspace (records, review, referrals, consultant opinions) is installable too. The navigation shows an **Install** button where the browser supports it, and Share → Add to Home Screen guidance on iOS. The service worker caches only the application shell for faster start-up and an offline fallback; `/api/` requests are never intercepted or cached, so clinical data always comes from the server.

## Install

- **Android (Chrome, Edge, Samsung Internet):** open the link, then tap **Install** (or menu → Install app / Add to Home screen).
- **iPhone/iPad (Safari):** open the link, tap Share, then **Add to Home Screen**.

## Publish

Hosted deployment is explicit through the Vercel CLI (see [deployment](deployment.md)). After merging, run `vercel deploy --prod --yes --regions fra1`. The apps are then at:

- Workspace: `https://ncdai-2.vercel.app/`
- Offline consult: `https://ncdai-2.vercel.app/mobile/`

`vercel.json` serves `sw.js` with `Cache-Control: no-cache` so each deployment reaches installed apps promptly, and the existing content-security policy (`script-src 'self'`) is kept: the mobile app has no inline scripts and no third-party requests.

A native store wrapper (for example Capacitor pointing at the hosted URL) can be added later if Play Store or App Store distribution is needed; it is not required to install and share the app.
